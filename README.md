# 拼豆稿

把普通图片转换成适合 104 × 104 或 52 × 52 底板的拼豆像素稿。所有图片处理都在浏览器本地完成。

## 主要功能

- 自定义成品横向豆数，按指定比例自动计算纵向豆数
- 只使用 MARD 标准 221 色号，并可限制成品色号总数（2–32 色）
- 边缘保留降噪和孤立小色块清理
- 裁切填满或完整显示原图
- 缩放、移动、亮度、对比度、饱和度、锐化、去背景与可选抖动混色
- 画笔、橡皮、填充、吸色、整色替换、框选移动，以及 50 步撤销/重做
- 管理自己的 MARD 库存，只用现有色号生成，并统计缺豆与推荐替代色
- 手机制作模式：按色号高亮、逐格标记完成并自动保存进度
- 自由选择是否在每颗豆上标注对应的 MARD 色号
- 图纸包含四边行列号和底部 MARD 色号用量清单
- A4 PDF 清晰分页或 1:1 实物尺寸打印，104 底板标明四个 52 × 52 拼接区
- 本地自动保存、最近项目和可分享的 `.pindou` 项目文件
- 下载原始尺寸像素 PNG、完整图纸 PNG 和库存/购买清单 CSV

默认参数对应示例：104 × 104 底板、90 px 宽、9:4 比例、40 px 自适应高度、最多 16 色。

## 在线使用

[直接打开拼豆稿（GitHub Pages）](https://earnbabysol.github.io/pindou-studio/)

无需安装，上传的图片只在当前浏览器中处理。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 验证

```bash
npm test
```
