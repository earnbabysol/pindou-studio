# 拼豆稿

把普通图片转换成适合 104 × 104 或 52 × 52 底板的拼豆像素稿。所有图片处理都在浏览器本地完成。

## 主要功能

- 自定义成品横向豆数，按指定比例自动计算纵向豆数
- 限制成品颜色总数（2–32 色）
- 边缘保留降噪和孤立小色块清理
- 裁切填满或完整显示原图
- 下载原始尺寸像素 PNG、带网格底板 PNG 和配色用量 CSV

默认参数对应示例：104 × 104 底板、90 px 宽、9:4 比例、40 px 自适应高度、最多 16 色。

## 在线使用

[直接打开拼豆稿](https://pindou-studio.mingzhe330.chatgpt.site)

无需安装，上传的图片只在当前浏览器中处理。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 验证

```bash
npm test
```
